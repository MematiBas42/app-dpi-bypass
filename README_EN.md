A root-level selective Per-App DPI and DoH (DNS over HTTPS) circumvention module for Android, powered by the **`nfqws` (zapret)** engine and **Zygisk + DobbyHook**.

Without establishing a `VpnService` (`tun0`) interface or altering global system network settings, it processes TCP/UDP traffic **strictly for selected applications** (such as Discord) at the Linux kernel Netfilter (`iptables` / `NFQUEUE`) level, and transparently intercepts DNS lookups at the Bionic libc level to resolve them through encrypted DoH.

---

## 🚀 Key Features

### 1. Selective Per-App DPI Circumvention
- Utilizes the Linux kernel `owner --uid-owner` Netfilter match.
- Only traffic generated by applications explicitly listed in `apps.list` is directed to the desync engine.
- Banking, governmental, and local network applications remain untouched; because no system-wide VPN interface is created, banking applications **will not trigger "VPN Detected" security warnings**.

### 2. Per-App DoH (DNS over HTTPS) via Zygisk + DobbyHook
- Neutralizes ISP-level DNS poisoning, hijacking, and SNI blocks directly inside the target application's process.
- **Linker-Independent DobbyHook Architecture:** Directly patches symbol memory addresses without relying on Bionic dynamic linker hooks, fully compatible with Android 15, 16, and 17 (API 35–37).
- **Dual-Architecture Support (64-bit & 32-bit):** Supports both 64-bit (`arm64-v8a`) and 32-bit (`armeabi-v7a`) Android processes (e.g., Discord mobile client runs as a 32-bit process).
- **Zero-Footprint on Unselected Apps:** For processes not present in the target list, the Zygisk library is unloaded immediately (`dlclose`) during `preAppSpecialize`.
- **Fail-Safe Fallback:** If the local DoH daemon becomes unreachable, queries automatically fall back to the system's original DNS resolver to prevent app crashes.

### 3. Advanced KernelSU & APatch WebUI v2.0
- **Apps:** Live search, user/system app filtering, quick-select chips for popular services (Discord, YouTube, Instagram, X, etc.).
- **Presets:** 1-click battle-tested DPI strategies (`discord_optimal`, `split_sni_compatible`, `fake_badsum_autottl`, `multisplit_midsni`, `disorder_sni`), plus custom local profile management with clipboard paste support.
- **Auto-Tune:** Automated desync benchmark suite that tests candidate strategies against a target domain (e.g., `discord.com`) and applies the optimal winning strategy with one click.
- **DoH:** Quick presets for public DoH providers (Cloudflare, Google, Quad9, AdGuard) or custom upstream URLs, along with a live DNS query latency test tool.
- **Advanced:** Fine-grained manual controls for TCP/UDP desync methods (`fake`, `split`, `disorder`, `multisplit`), split positions (`sni`, `midsni`), fooling techniques (`md5sig`, `badsum`), TTL tuning, and raw `nfqws` arguments. Features live CLI preview and clipboard synchronization.

### 4. Full WebRTC and Voice / Video Channel Support
- Standard and alternative TLS/HTTPS ports: `80, 443, 2053, 2083, 2087, 2096, 8443`.
- Discord voice channels and WebRTC UDP ports: `50000:65535` and `19294:19344` (`filter-l7=discord`).
- Guarantees smooth and uninterrupted "RTC Connected" voice states in Discord.

### 5. Zero VPN Overhead & Minimal Battery Consumption
- Leaves the single Android `VpnService` slot free for other tools.
- Operates directly via kernel packet queues (NFQUEUE) without userland proxy loops, causing zero measurable battery drain or device thermal throttling.

## 🛠️ Installation

1. Download `app-dpi-bypass-v2.0.0.zip` from the **Releases** section (or build it yourself using `./package.sh`).
2. Open **KernelSU Manager**, **APatch**, or **Magisk**.
3. *Note:* Ensure Zygisk support is enabled in your root manager (e.g., ZygiskNext or Zygisk-on-KernelSU for KernelSU).
4. Navigate to the **Modules** tab, tap **Install from storage**, and select the zip archive.
5. Perform a full **hardware reboot** of the device (a cold reboot is required for Zygote to load the Zygisk libraries).

## 📱 Usage

### 1. WebUI Management (Recommended)
- Open **KernelSU** or **APatch** manager.
- Tap the **WebUI** button next to the **App DPI Bypass** module.
- In the **Apps** tab, select your target applications and tap **Save & Apply**.
- Under **Presets** or **Auto-Tune**, select or benchmark the most effective DPI strategy for your ISP.
- Under **DoH**, configure your preferred DNS provider and verify resolution via **Test Resolution**.

### 2. Action Button
- Toggle the DPI and DoH engine on or off with a single tap using the module's **Action** button in the manager.

### 3. Command-Line Interface (CLI / Termux / Root Shell)
Manage the module directly via `dpi_ctl.sh` in a root shell:

```bash
# View engine status, traffic volume, and DoH metrics
sh /data/adb/modules/app-dpi-bypass/dpi_ctl.sh status

# Toggle DPI and DoH services on/off
sh /data/adb/modules/app-dpi-bypass/dpi_ctl.sh toggle

# Add a package to the target list and apply rules
sh /data/adb/modules/app-dpi-bypass/dpi_ctl.sh add-app com.discord

# Remove a package from the target list
sh /data/adb/modules/app-dpi-bypass/dpi_ctl.sh del-app com.discord

# Apply a preset strategy
sh /data/adb/modules/app-dpi-bypass/dpi_ctl.sh set-preset discord_optimal

# Run an automated strategy benchmark against a domain
sh /data/adb/modules/app-dpi-bypass/dpi_ctl.sh autotune discord.com

# Test DNS resolution over DoH
sh /data/adb/modules/app-dpi-bypass/dpi_ctl.sh test-dns discord.com

# Reload Netfilter rules and daemons
sh /data/adb/modules/app-dpi-bypass/dpi_ctl.sh reload
```

## 🔨 Building from Source

### 1. Compile DoH Forwarder (Go)
```bash
cd src/doh_forwarder
GOOS=android GOARCH=arm64 go build -ldflags="-s -w" -o ../../bin/doh_forwarder .
```

### 2. Compile Zygisk Modules (Android NDK)
```bash
cd src/zygisk
# 64-bit arm64-v8a
cmake -B build-arm64 -DCMAKE_TOOLCHAIN_FILE=$ANDROID_NDK_ROOT/build/cmake/android.toolchain.cmake -DANDROID_ABI=arm64-v8a -DANDROID_PLATFORM=android-26 -DCMAKE_BUILD_TYPE=Release
cmake --build build-arm64 --target app_dpi_zygisk
cp build-arm64/libapp_dpi_zygisk.so ../../zygisk/arm64-v8a.so

# 32-bit armeabi-v7a
cmake -B build-arm32 -DCMAKE_TOOLCHAIN_FILE=$ANDROID_NDK_ROOT/build/cmake/android.toolchain.cmake -DANDROID_ABI=armeabi-v7a -DANDROID_PLATFORM=android-26 -DCMAKE_BUILD_TYPE=Release
cmake --build build-arm32 --target app_dpi_zygisk
cp build-arm32/libapp_dpi_zygisk.so ../../zygisk/armeabi-v7a.so
```

### 3. Build Flashable Zip
```bash
chmod +x package.sh
./package.sh
```
The output package will be generated at `dist/app-dpi-bypass-v2.0.0.zip`.
